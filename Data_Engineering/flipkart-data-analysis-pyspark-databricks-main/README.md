Data Analysis Using PySpark on Databricks
📌 Project Overview

This project demonstrates an end-to-end data engineering pipeline for analyzing Flipkart data using PySpark on Databricks. The goal is to explore, clean, transform, and analyze e-commerce product data to extract meaningful insights that support business decision-making.

By leveraging PySpark’s distributed processing capabilities within Databricks, the project shows how to handle raw datasets, apply transformations, and generate valuable analytics in a scalable and efficient manner.

🔗 Project Link: Databricks Notebook

⚙️ Steps Involved
🔍 1. Data Exploration

Loaded the Flipkart dataset into Databricks.

Explored schema, structure, and key fields like product_id, title, rating.

Referred to a data dictionary for column descriptions.

🧹 2. Data Cleaning

Handled missing values and invalid records.

Removed irrelevant/duplicate rows.

Standardized column formats for consistency.

⚡ 3. Data Processing & Analysis

Applied filters (e.g., only valid product ratings).

Performed aggregations to compute totals, averages, and trends.

Identified patterns in product performance across categories.

📊 4. Insights & Results

Highlighted top-rated products with consistent performance.

Analyzed key categories driving customer satisfaction.

Discovered trends in product ratings and sales potential.

🚀 Tech Stack

Databricks – Cloud-based data platform

PySpark – Data cleaning, transformation & analysis

Delta Lake (Databricks) – For efficient storage & querying
