☕ Coffee Sales Dashboard - Excel Project
![Dashboard Screenshot](images/coffee%20order%20dahsboard.png)  

This Excel Dashboard Project analyzes coffee sales data using Pivot Tables, XLOOKUP, INDEX, Slicers, and Timelines.
It is inspired by a tutorial from Mo Chen on YouTube and showcases my ability to perform data analysis and visualization using Microsoft Excel.

📊 Dashboard Overview

The dashboard provides interactive visualizations and insights into:

Total Sales Trend over time (Line Chart)

Sales by Country (Bar Chart)

Top 5 Customers (Bar Chart)

Dynamic Filtering using Slicers (Roast Type Name, Size, Loyalty Card)

Time-based Filtering using Excel Timeline

🧠 Skills Demonstrated

✅ Data Lookup & Retrieval using XLOOKUP() and INDEX()

✅ Pivot Tables for summarizing and analyzing large datasets

✅ Interactive Dashboards with Slicers and Timelines

✅ Data Cleaning (removing duplicates, handling missing values)

✅ Professional Dashboard Design with a clean, minimal layout
