🩺 Diabetes Predictioner ML Project

This repository contains my end-to-end machine learning project for predicting the likelihood of diabetes using health-related data. The project covers the complete ML lifecycle — from data gathering and preprocessing to model building and deployment as a web application.

🚀 Project Overview

The objective of this project is to develop a machine learning model that can predict whether a person is likely to have diabetes based on their health parameters.
I also built a Flask web application that allows users to input their health details and instantly receive predictions.
The app is deployed on Heroku for easy access.

📌 Project Workflow

Data Gathering – Used publicly available diabetes datasets.

Exploratory Data Analysis (EDA) – Identified key patterns, distributions, and correlations.

Data Visualization – Built plots and graphs for insights.

Data Preprocessing – Cleaned, normalized, and prepared data for modeling.

Model Building – Trained multiple ML models and selected the best one.

Model Evaluation – Compared models using accuracy, precision, recall, F1-score.

Deployment – Integrated the model with Flask and deployed on Heroku.

🧠 Machine Learning Model

Framework: scikit-learn

Algorithms Tried: Logistic Regression, Decision Tree, Random Forest

Selected Features:

Pregnancies

Insulin Level

Age

BMI (Body Mass Index)

Blood Pressure

Glucose Level

Skin Thickness

Diabetes Pedigree Function

Output: The model predicts whether the person is Diabetic (Yes/No).



Functionality:

User inputs health details via a form.

Model processes the data.

Result is displayed on a new page.
