🌸 Iris Dataset Analysis - Classification

A machine learning project for Iris Flower Classification.
We build and compare multiple classification algorithms to correctly identify the species of iris flowers.

👨‍💻 Author: Muhammad Adnan

📊 Dataset Information

The dataset contains 3 classes of 50 instances each, representing three species of iris plants:

Iris Setosa

Iris Versicolour

Iris Virginica

🔹 One class is linearly separable from the other two.
🔹 The other two are not linearly separable.

Download Dataset: Kaggle - Iris Dataset

Attribute Details

Sepal Length (cm)

Sepal Width (cm)

Petal Length (cm)

Petal Width (cm)

Species → Setosa / Versicolour / Virginica

pandas – Data handling

We compared multiple algorithms for classification:
