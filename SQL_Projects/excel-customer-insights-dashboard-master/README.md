Excel Sales & Customer Insights Dashboard
📌 Project Overview

This project demonstrates how Microsoft Excel can be used as a complete end-to-end tool for data cleaning, transformation, and dashboard creation.
I worked on a dataset containing customer demographics and transactional data to perform cleaning, categorization, and analysis, followed by building an interactive dashboard with meaningful insights.

This project highlights my ability to use Excel not just for spreadsheets, but for advanced analytics and visualization, making data easy to understand for decision-makers.

🚀 Features

Data Cleaning & Preparation

Removed duplicates and null values

Standardized formats for dates, numbers, and text

Replaced coded values (e.g., M → Married, S → Single)

Advanced Data Categorization

Created age brackets using nested IF statements

Classified customers into groups for targeted insights

Data Analysis with Pivot Tables

Summarized customer demographics and transactions

Segmented bike purchase behavior by income, age, and commute distance

Visualizations & Dashboard

Bar Charts → Income vs. Bike Purchase by Gender

Line Charts → Bike purchases by age groups

Pie Charts → Customer commute distance distribution

Interactive Slicers → Filter dashboard in real-time

🛠 Tools & Techniques

Microsoft Excel → Data cleaning, transformations, pivot tables, and dashboard

Pivot Tables → For summarizing and analyzing data

Nested IF Statements → Custom categorization (age brackets, groups)

Charts (Bar, Line, Pie) → Visual storytelling

Slicers → Dashboard interactivity

📂 Project File Structure

Raw_Data_Sheet → Original dataset (unmodified)

Pivot_Tables_Sheet → Data summaries and analysis tables

Dashboard_Sheet → Final interactive dashboard

✅ Conclusion

This project demonstrates my ability to use Excel for end-to-end data analysis: from raw data cleaning to interactive dashboard creation. It showcases practical skills in data preprocessing, pivot table analysis, and visualization techniques that can directly support business decision-making.
